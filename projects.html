ABM.NET Framework

A distributed agent-based modelling system in C#/.NET 8. I planned the work for the whole team, then built the scenario setup and the tools researchers use to compare many runs.

  • Planning and leadership. Directed the work breakdown structure: split the architecture into task packages, estimated durations, and assigned backend, frontend and DevOps roles.
  • Configuration module. Parses JSON and YAML scenario files into a validated SimulationConfig object for the core engine. It reports every configuration error in one pass, and its public interface let teammates on agent logic and persistence work independently.
  • Batch experiments (Compare). A Monte Carlo runner that executes up to 100 simulation runs in the background, each with its own random seed.
  • Aggregation. Calculates the average, lowest, highest and standard deviation across runs for each key outcome.
  • Charts and export. Chart.js plots of the average trajectory with a shaded spread band, plus one-click CSV export.
  • C#
  • .NET 8
  • JSON / YAML
  • xUnit
  • Chart.js
  • Monte Carlo
